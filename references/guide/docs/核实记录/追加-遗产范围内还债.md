# 追加：第 25 节第 11 条，亲人留下欠债，继承人只用继承到的遗产去还，不想担就书面放弃继承

2026-10-14。全书原来只有第 29 节第 13 条（别拿死当还债）在收益栏里带过一句民法典第一千一百五十九、一千一百六十一条，讲的是「自杀还债不通」，不讲继承人怎么应对。本条讲继承人这一侧：要不要放弃、什么时候放弃、怎么放弃、被起诉和催收时怎么办，不算重复。第 5 节第 44 条（保单上把受益人写成具体的人）提到保险金算遗产时先清偿税和债，只是一句，也不重复。追加在第 25 节末尾，没有插在中间。本节没有节首导览。

## 1. 民法典（2020，现行）
- URL：<https://flk.npc.gov.cn/detail?id=ff808081729d1efe01729d50b5c500bf>。2026-10-14 用 flk 搜索 API 核到 `sxx: 3`（有效），再用 `/law-search/download/mobile?format=docx&bbbs=ff808081729d1efe01729d50b5c500bf` 下 docx（要跟随 302），解出 word/document.xml 逐字核对。
- 第一千一百六十一条：「继承人以所得遗产实际价值为限清偿被继承人依法应当缴纳的税款和债务。超过遗产实际价值部分，继承人自愿偿还的不在此限。」「继承人放弃继承的，对被继承人依法应当缴纳的税款和债务可以不负清偿责任。」
- 第一千一百五十九条：「分割遗产，应当清偿被继承人依法应当缴纳的税款和债务；但是，应当为缺乏劳动能力又没有生活来源的继承人保留必要的遗产。」
- 第一千一百二十四条第一款：「继承开始后，继承人放弃继承的，应当在遗产处理前，以书面形式作出放弃继承的表示；没有表示的，视为接受继承。」
- 第一千一百四十五条：「继承开始后，遗嘱执行人为遗产管理人；没有遗嘱执行人的，继承人应当及时推选遗产管理人；继承人未推选的，由继承人共同担任遗产管理人；没有继承人或者继承人均放弃继承的，由被继承人生前住所地的民政部门或者村民委员会担任遗产管理人。」
- 第一千一百四十七条：「遗产管理人应当履行下列职责：（一）清理遗产并制作遗产清单；（二）向继承人报告遗产情况；……（四）处理被继承人的债权债务；……」
- 第一千一百五十三条第一款：「夫妻共同所有的财产，除有约定的外，遗产分割时，应当先将共同所有的财产的一半分出为配偶所有，其余的为被继承人的遗产。」
- 第一千零六十四条第一款：「夫妻双方共同签名或者夫妻一方事后追认等共同意思表示所负的债务，以及夫妻一方在婚姻关系存续期间以个人名义为家庭日常生活需要所负的债务，属于夫妻共同债务。」第二款超出日常生活需要的，债权人能证明用于共同生活、共同生产经营或者双方共同意思表示的，也算。备注只写了「一起签字借的、为家里日常开销借的」两种，第二款的例外没展开。

## 2. 最高人民法院关于适用《中华人民共和国民法典》继承编的解释（一）（法释〔2020〕23 号）
- URL：<https://www.court.gov.cn/fabu/xiangqing/282091.html>（2026-10-14 curl 直连取到）
- 第三十二条：「继承人因放弃继承权，致其不能履行法定义务的，放弃继承权的行为无效。」
- 第三十三条：「继承人放弃继承应当以书面形式向遗产管理人或者其他继承人表示。」
- 第三十五条：「继承人放弃继承的意思表示，应当在继承开始后、遗产分割前作出。遗产分割后表示放弃的不再是继承权，而是所有权。」
- 第三十四条（诉讼中口头放弃要做笔录签名）、第三十六条（遗产处理前或诉讼中反悔由法院决定是否承认，处理后反悔不予承认）、第三十七条（效力追溯到继承开始）核到了，条目篇幅有限没写。

## 4. 重庆案（重庆市人民检察院官网）

- 「李某去世后，其配偶、女儿作为法定继承人，已实际继承包括养老保险、职业年金个人账户余额等遗产」；「李某死后，其配偶提取了属于李某遗产的基本养老保险金和职业年金」；「二人均未明示放弃继承，依法视为接受继承」。
- 「2025年11月，在法院与检察机关的共同努力下，张某与李某配偶当场达成和解，当场履行完毕」。
- 原文没写还了多少，条目只写「和解还清」。原文前面说「均声明放弃继承」、后面又说「均未明示放弃」，没解释两句怎么对上，条目照「声明放弃，但取走了钱，被认定没有明示放弃」的顺序写，不推断理由。

## 5. 过程成本
- 民事诉讼法（2023 修正），上海市发展改革委转载页 <https://fgw.sh.gov.cn/ys-syjf-zc-2.4.1-h5/20240408/073febdb2b04464390546232d4089f51.html>：第一百五十二条「人民法院适用普通程序审理的案件，应当在立案之日起六个月内审结。有特殊情况需要延长的，经本院院长批准，可以延长六个月；还需要延长的，报请上级人民法院批准。」第一百六十四条「人民法院适用简易程序审理案件，应当在立案之日起三个月内审结。」
- 诉讼费用交纳办法 <https://www.gov.cn/zhengce/zhengceku/2008-03/28/content_6929.htm>：第六条列的诉讼费用只有「（一）案件受理费；（二）申请费；（三）证人、鉴定人、翻译人员、理算人员在人民法院指定日期出庭发生的交通费、住宿费、生活费和误工补贴」，没有律师费；第二十九条「诉讼费用由败诉方负担，胜诉方自愿承担的除外。」
- 催收的应对只写了「要凭据、让对方找遗产管理人或起诉、超出部分别签还款承诺」，依据是第一千一百六十一条「自愿偿还的不在此限」。没有找到专管「催收找死者家属」的官方规定，没写报警、投诉这类具体渠道。

## 没收的内容和理由
- 「人民法院报刊文：债务人死亡，继承人书面放弃继承的，是否需要承担」：检索结果是律所网站转载，没去找原报，没引。
- 「最高院裁判观点：遗产未分割时判继承人承担连带责任没有法律依据」：只有搜狐转述，没引。
- 无锡司法局、濉溪县的普法稿：内容和上面两件检察案例重复，没引。
- 放弃继承要不要公证：民法典和解释都只要求书面形式，银行、不动产登记实务常要公证，但没找到官方原文，条目不写。
- 丧葬补助金、抚恤金算不算遗产：没找到能逐字核对的现行官方规定，条目不写，只写了重庆案里点名算作遗产的养老保险金和职业年金，以及本节第 9 条已写明「可以继承」的公积金余额和养老保险个人账户余额。
