# 追加：第 8 节第 3 条并入屏幕共享诈骗

2026-10-14。候选是「陌生人以客服、警察、平台退款、贷款审核等名义让你打开屏幕共享，一律拒绝挂断」。

## 为什么并入、不另开
- 第 8 节第 3 条（反诈硬规则）的成本栏和说人话里原本就写着「凡是让你转账、共享屏幕、下载陌生 App、点链接、报验证码的，先挂断」。动作相同，按「不写重复条目」第三问并进这一条。
- 原条缺的是「为什么共享屏幕危险」，所以只在收益栏「冒充客服」一类后面补了机制和警方提示两句，来源栏补两个链接。
- 说人话原来就有「共享屏幕」，且已经 114 字，接近 120 字上限，没动。
- 证据等级、收益量级不变（B、大）：新增的仍是官方宣传口径，没有「照做之后少被骗多少」的数字。
- 工信部、国家反诈中心 App 的原文没取到（mps.gov.cn 长期不可达），改用福建省公安厅识骗技巧专栏，和本条既有来源同一个栏目。

## 1. 福建省公安厅·识骗技巧：警惕「共享屏幕」类诈骗手段（2022-08-18，来源福建警方防骗咨询热线）
- URL：<https://gat.fujian.gov.cn/ztzl/fjjffpzxrx/spjq/202208/t20220818_5977906.htm>（2026-10-14 curl 直取）
- 「一旦下载会议APP，输入"会议ID"……让你点击"共享屏幕"，点击开始，就会开始所谓的"视频会议"，紧接着你在手机上所有的操作，包括消息弹窗、短信验证码、密码输入等都会被看得一清二楚。」
- 「陌生人要求你下载APP，让你开通"共享屏幕"的一定是盯上你的钱」
- 页面案例：冒充京东金融客服称取消校园贷，视频会议并共享屏幕，被骗 136037 元（只作「发生过」用，没写进条目）。

## 2. 福建省公安厅·识骗技巧：「中银会议」「银联会议」「抖音会议」这些APP都是诈骗软件（2025-05-12，转载上海反诈中心）
- URL：<https://gat.fujian.gov.cn/ztzl/fjjffpzxrx/spjq/202505/t20250512_6912823.htm>（2026-10-14 curl 直取）
- 「通过'屏幕共享'功能，骗子能够看到事主在手机上的所有操作，事主输入的银行卡账号、密码、验证码一览无余，通过'远程控制'甚至能够直接操控事主的手机，最终完成转账诈骗。」
- 警方提示：「凡是提到"会议号""屏幕共享""远程控制"的都是诈骗。」
